# Notebook Execution Order

The analysis is designed to be executed in the following order.

1. `01_project_setup_and_config.ipynb`
2. `02_load_merge_nhanes_data.ipynb`
3. `03_feature_tiers_and_splits.ipynb`
4. `04_eda_cohort_characterization.ipynb`
5. `05_baseline_models_and_referral_policies.ipynb`
6. `06_neural_defer_to_lab_model.ipynb`
7. `07_budget_sweeps_and_pareto_frontier.ipynb`
8. `08_fairness_calibration_and_equity.ipynb`
9. `09_interpretability_and_defer_gate.ipynb`
10. `10_ablations_and_robustness.ipynb`
11. `11_final_synthesis_and_reproducibility.ipynb`

The workflow is sequential. Later notebooks consume serialized data, models, tables, and manifests generated by earlier notebooks.

For reproducibility, model selection and threshold selection are performed using the training and validation periods. The 2017–2018 temporal test period is reserved for final evaluation.
