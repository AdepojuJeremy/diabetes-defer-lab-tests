# Project Metadata

**Title:** Learning to Defer to Lab Tests: Cost-Sensitive Selective Prediction for Diabetes Screening Cascades

**Primary dataset:** NHANES 2011–2018

**Primary evaluation design:** Temporal train/validation/test split

- Train: NHANES 2011–2014
- Validation: NHANES 2015–2016
- Test: NHANES 2017–2018

**Primary screening endpoint:** Screen-detected diabetes defined operationally as HbA1c >= 6.5% or fasting plasma glucose >= 126 mg/dL among adults without known diagnosed diabetes.

**Primary laboratory budget:** 35%

**Primary normalized costs:**

- Laboratory referral: 1
- False negative: 10
- False positive: 2

**Repository scope:** Computational research release containing notebooks, final figures, tables, supplementary analyses, metadata, and reproducibility documentation.

Participant-level NHANES data are not redistributed in this repository.
